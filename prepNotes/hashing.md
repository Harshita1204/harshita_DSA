# 📘 Hashing in Data Structures (DSA)

## 🔹 What is Hashing?

Hashing is a technique used to **map data (keys)** to a fixed-size table using a **hash function**.

-> It enables very fast operations like:

* Searching
* Insertion
* Deletion

⏱️ Average Time Complexity: **O(1)**

---

## 🔹 Key Concepts

### 1. Hash Function

A hash function converts a key into an index of the hash table.

Example idea:

* Input: Key (e.g., 23)
* Output: Index (e.g., 23 % table_size)

-> A good hash function should:

* Be fast to compute
* Distribute keys uniformly
* Minimize collisions

---

### 2. Hash Table

A hash table is a **data structure (array)** that stores data using indices generated by the hash function.

---

### 3. Collision

A collision occurs when **two different keys map to the same index** in a hash table.

Example:

* h(10) = 0
* h(20) = 0
  ➡ Collision occurs

---

## 🔹 Collision Handling Techniques

### 1. Separate Chaining

* Each index stores a **linked list (or vector)**
* Multiple elements can exist at same index

-> Easy to implement
-> Extra memory required

---

### 2. Open Addressing

All elements are stored in the hash table itself.

#### a) Linear Probing

* Check next index sequentially

#### b) Quadratic Probing

* Check indices using square increments

#### c) Double Hashing

* Use a second hash function

-> No extra memory
-> Clustering problem

---

## 🔹 Load Factor

Load factor tells how full the hash table is.

Formula:
Load Factor = Number of elements / Size of table

 If load factor is high → more collisions
 Ideal load factor ≈ 0.7

---

## 🔹 Advantages of Hashing

-> Very fast (O(1) average time)
-> Efficient for large datasets
-> Simple lookup operations
-> Widely used in real-world applications

---

## 🔹 Disadvantages of Hashing

-> Collisions are unavoidable
-> Performance depends on hash function
-> May use extra memory
-> Worst case time complexity is O(n)

---

## 🔹 Applications of Hashing

* Dictionaries / Maps
* Database indexing
* Password storage (hashing passwords)
* Caching
* Compiler symbol tables

---

## 🔹 Time Complexity

| Operation | Average Case | Worst Case |
| --------- | ------------ | ---------- |
| Insert    | O(1)         | O(n)       |
| Search    | O(1)         | O(n)       |
| Delete    | O(1)         | O(n)       |
